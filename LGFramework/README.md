# LGFramework

A modular, hardware-accelerated **Liquid Glass & Adjustable Blur** rendering framework for iOS jailbreak tweaks (iOS 15 – iOS 16+ Rootless / RootHide).

LGFramework upgrades the original `liquidass-next` research into a clean, multi-view rendering pipeline supporting **live glass refraction**, **adjustable gaussian blur**, **specular 3D edge highlights**, and **physics-driven interactive controls**.

## 🔬 How Multi-View Liquid Glass Rendering Works

Stock iOS `UIVisualEffectView` is a static blur with fixed presets. Real **Liquid Glass (iOS 26)** requires a multi-pass compound stack:

```
┌────────────────────────────────────────────────────────┐  Top Layer: Interactive Content / Glyphs
│  UILabel / Icons / Controls (Pure White or Tinted)      │
├────────────────────────────────────────────────────────┤  Layer 4: Specular 3D Rim (LGSpecularHighlightView)
│  CAGradientLayer (Top-Left 0.65α, Bottom-Right 0.35α)   │
├────────────────────────────────────────────────────────┤  Layer 3: Translucent Tint / Dimming
│  Dark Tint (0.35α) or Custom Accent Color               │
├────────────────────────────────────────────────────────┤  Layer 2: Liquid Glass Refraction (LGLiveBackdropView)
│  CABackdropLayer + "dylv.liquidglass.refraction"        │
├────────────────────────────────────────────────────────┤  Layer 1: Adjustable Blur (LGAdjustableBlurView)
│  CABackdropLayer + "gaussianBlur" (inputRadius: 4.0pt)  │
└────────────────────────────────────────────────────────┘  Background: Wallpaper / System Views
```

1. **Adjustable Blur (`LGAdjustableBlurView`):** Uses private `CABackdropLayer` to sample background pixels at scale and applies `CAFilter` `"gaussianBlur"` with a custom radius (0.0 to 20.0 pt).
2. **Liquid Glass Refraction (`LGLiveBackdropView`):** Captures the blurred backdrop and runs the Metal compute shader (`dylv.liquidglass.refraction`) in `backboardd` to distort light based on corner curvature and index of refraction (IOR 1.5).
3. **Specular Rim (`LGSpecularHighlightView`):** A diagonal linear gradient masked to the continuous squircle border gives the illusion of physical light reflections on the top-left and bottom-right edges.
4. **Interactive Physics (`LGButtonView`):** Applies dynamic squash & stretch transformations (`CGAffineTransformMakeScale`) and renders a radial inner glow that tracks the user's finger.

## 🚀 Quick Start & Code Examples

### 1. Basic Liquid Glass Backdrop (5 Lines)
Add live glass refraction behind any view or card:

```objc
#import "LGFramework.h"

// 1. Create container view
UIView *glassCard = [[UIView alloc] initWithFrame:CGRectMake(20, 100, 300, 200)];
glassCard.layer.cornerRadius = 24;
glassCard.clipsToBounds = YES;

// 2. Add Live Glass Refraction Layer
LGLiveBackdropView *glassView = [[LGLiveBackdropView alloc] initWithFrame:glassCard.bounds];
glassView.autoresizingMask = UIViewAutoresizingFlexibleWidth | UIViewAutoresizingFlexibleHeight;
[glassCard addSubview:glassView];

[self.view addSubview:glassCard];
```

### 2. Full iOS 26 Glass Container (Refraction + Blur + Specular Rim)
To get the authentic, ultra-smooth iOS 26 glass effect:

```objc
#import "LGFramework.h"

UIView *container = [[UIView alloc] initWithFrame:CGRectMake(20, 100, 320, 180)];
container.layer.cornerRadius = 32;
container.clipsToBounds = YES;

// Layer 1: Hardware-accelerated base blur
LGAdjustableBlurView *blur = [[LGAdjustableBlurView alloc] initWithFrame:container.bounds blurRadius:4.0];
blur.autoresizingMask = UIViewAutoresizingFlexibleWidth | UIViewAutoresizingFlexibleHeight;
[container addSubview:blur];

// Layer 2: Live Liquid Glass Refraction
LGLiveBackdropView *glass = [[LGLiveBackdropView alloc] initWithFrame:container.bounds];
glass.autoresizingMask = UIViewAutoresizingFlexibleWidth | UIViewAutoresizingFlexibleHeight;
[container addSubview:glass];

// Layer 3: Dark tint for high contrast
UIView *darkTint = [[UIView alloc] initWithFrame:container.bounds];
darkTint.backgroundColor = [UIColor colorWithWhite:0.0 alpha:0.30];
darkTint.autoresizingMask = UIViewAutoresizingFlexibleWidth | UIViewAutoresizingFlexibleHeight;
darkTint.userInteractionEnabled = NO;
[container addSubview:darkTint];

// Layer 4: Specular 3D highlight rim
LGSpecularHighlightView *specular = [[LGSpecularHighlightView alloc] initWithFrame:container.bounds cornerRadius:32];
specular.autoresizingMask = UIViewAutoresizingFlexibleWidth | UIViewAutoresizingFlexibleHeight;
[container addSubview:specular];

// Reapply filters over first few seconds to guarantee registration race safety
for (NSNumber *delay in @[@0.5, @1.5, @3.0]) {
    dispatch_after(dispatch_time(DISPATCH_TIME_NOW, (int64_t)(delay.doubleValue * NSEC_PER_SEC)), dispatch_get_main_queue(), ^{
        [glass forceReapplyForRegistrationRace];
    });
}
```

## ⚡ Performance & Stability Guidelines

### 1. OOM Prevention & Idempotent Filter Checking
* **Problem:** In UIKit, `layoutSubviews` and `didMoveToWindow` fire dozens of times during animations or drags. If a `CAFilter` is re-instantiated on every call, `CoreAnimation` / `backboardd` allocates new surface render targets on every frame, quickly leading to an Out-Of-Memory crash.
* **Solution:** Both `LGLiveBackdropView` and `LGAdjustableBlurView` include built-in **idempotent guards**. They inspect `layer.filters` and skip allocation if the filter and radius are already applied.

### 2. Optimal `qualityScale`
* `CABackdropLayer` defaults to full screen resolution (`scale = 1.0`), which causes significant GPU load when multiple glass elements are visible.
* LGFramework sets `qualityScale = 0.35` by default. This delivers **120 FPS ProMotion fluidity** with zero perceived loss in refraction fidelity.

### 3. Power-Saving when Homescreen is Hidden
When the user opens an app, enters App Switcher, or triggers edit mode:
```objc
// Completely disable hardware sampling to save GPU/battery
[backdropLayer setValue:@NO forKey:@"enabled"];
// Or hide the views
backdropView.hidden = YES;
```
